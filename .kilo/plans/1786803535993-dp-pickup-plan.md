## Design Decisions

### D1: Remove unused `memoize` and `PureMemo`

**Rationale:** Both are new code with zero consumers. `memoize` is a decorator that monkey-patches `_memo`, `clear`, and `stats` onto the wrapped function — a maintenance liability. `PureMemo` is a single-method class (`get_or_compute`) that's never instantiated. The plan document speculated they'd be "kept for future algorithms," but dead code in a library expands the attack surface and confuses readers. Git history preserves them if needed later.

**Action:** Delete `memoize` and `PureMemo` from `_memoize.py`. Remove their docstring bullets. Remove `hashlib` and `Awaitable`/`Callable` imports that only served them. This resolves 5 of the 7 lint issues in `_memoize.py` at once.

### D2: `_make_key` is moot after D1

`_make_key` only existed to support `PureMemo.get_or_compute`. With `PureMemo` removed, delete `_make_key` entirely.

### D3: Remove broken `astar` strategy from `TreeCollector`

`TreeCollector._astar` cannot correctly implement LCP matching because its API
(`key_extractor(node) -> str | None`, `children_extractor(node) -> Iterable`)
does not expose path characters. The current condition
`self._key_extractor(child) is not None` checks whether a child is terminal,
not whether its character matches the target — this is a logic bug.

`MemoryCache._astar_collect` already exists with its own correct implementation
(accesses `ch == target[match_len]` via `current.children.items()`). No code
uses `TreeCollector(strategy="astar")`.

**Action:** Remove `astar` from `TreeCollector` supported strategies. Remove
`_astar` method. `MemoryCache._astar_collect` remains as the sole LCP
implementation.

**Validation consequence:** `test_astar_longest_common_prefix` and
`test_astar_regression_mismatch_resets` move from `test_recursion.py` to a
`MemoryCache` test in `test_components.py` (where the existing A* tests already
live). `test_invalid_strategy_raises` should test only `"dfs"` and `"bfs"` as
valid, with `"astar"` removed from the enum.

### D4: Keep `Memo` and `ResourceMemo` as tested, production primitives

These have real consumers and correctness implications. They get full lint cleanup and dedicated tests.

### D5: `daf/utils/__init__.py` barrel pattern

The DP analysis plan specifies `from daf._barrel import _public` + `__all__ = _public()` (empty). This maintains barrel consistency and makes it trivial to expose public symbols later.

**Action:** Add the two-line barrel pattern to `daf/utils/__init__.py` (currently empty/untracked).

### Test scenarios

**`Memo`:**
- `test_has_miss` — `has()` False before `set()`
- `test_get_raises_on_miss` — `get()` raises `KeyError`, increments `_iterations`
- `test_get_returns_on_hit` — `get()` returns value, increments `_cache_hits`
- `test_set_then_get` — `set()` then `get()` returns value
- `test_clear_resets` — after `clear()`, `has()` False, stats zeroed
- `test_stats_shape` — `stats()` returns `{"iterations", "cache_hits", "memo_size"}`

**`ResourceMemo`:**
- `test_lazy_init_same_object` — two `get()` calls for same key return identical object
- `test_different_keys_different_objects` — different keys produce different objects
- `test_concurrent_same_lock` — concurrent `get()` for same key returns same `asyncio.Lock`
- `test_clear_empties_store` — after `clear()`, `get()` creates new objects

**`TreeCollector`:**
- `test_dfs_collects_all_keys` — DFS returns all terminal keys
- `test_bfs_same_set_as_dfs` — BFS returns same set as DFS
- `test_none_root_returns_empty` — `None` root returns empty set for all strategies
- `test_invalid_strategy_raises` — unknown strategy raises `ValueError`
- `test_collect_tree_convenience` — `collect_tree()` delegates to `TreeCollector`

Note: `astar` strategy is removed from `TreeCollector` (D4). A* tests already
exist in `test_components.py` against `MemoryCache._astar_collect`, which has
its own correct implementation.

**`walk_tree`:**
- `test_callback_called_pre_order` — callback called once per node in pre-order
- `test_walk_tree_empty_children` — leaf node calls callback exactly once
- `test_walk_tree_nested` — nested structure visits all nodes

**`test_barrels.py` addition:**
- `test_no_barrel_defines_own_public` — scan all `daf/*/__init__.py` for `def _public`; all must import from `daf._barrel`
