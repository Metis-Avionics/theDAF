# Red Team Fixes: R19b, R3b, R21b, R19c

PR #17 at `ab70618` passes 115 tests and all quality gates. A fresh red-team
pass identified four interaction-level findings.

| ID | Finding | Severity |
|----|---------|----------|
| R19b | Generation local to `DataAccess`; stale resurrection across instances sharing cache | Medium-High |
| R3b | `delete_prefix("query:{resource_id}:")` collides when `resource_id` contains `:` | Medium |
| R21b | Algorithm input and `raw_data` share reference; algorithm can poison auth snapshot | Medium |
| R19c | Global generation advances on any mutation, invalidating unrelated resource caches | Low-Medium |

## Design Decisions

### D1: Generation lives in the shared cache, not in `DataAccess`

- Use reserved cache keys: `_daf_gen:{namespace}` → `int`
- `DataAccess` reads/writes generations through the existing `Cache` protocol
  (`get` / `set`). No protocol changes needed.
- The cache is the shared consistency boundary; invalidation and version authority
  are colocated.

### D2: Cache keys are resource-namespace-hashed

- Cache key: `query:{resource_namespace}:{semantic_digest}`
- Invalidation prefix: `query:{resource_namespace}:`
- `resource_namespace = sha256(resource_id.encode()).hexdigest()`
- The prefix is fixed-width and structurally unambiguous regardless of
  `resource_id` contents.

### D3: Per-resource generation

- Generation is scoped to a single resource, not global.
- Mutating resource A increments only A's generation.
- Resource B's cache entries remain valid.

### D4: Defensive copy before algorithm execution

- `raw_data = copy.deepcopy(data)` immediately after repository read.
- Algorithm receives the original `data` reference; `raw_data` is an
  independent snapshot for authorization and cache storage.
- This makes the raw/transformed invariant structural rather than trust-based.

## Implementation

All changes are in `src/daf/core/access.py` unless noted.

### Step 1: Add resource namespace helper

```python
def _resource_namespace(self, resource_id: str) -> str:
    return hashlib.sha256(resource_id.encode()).hexdigest()
```

### Step 2: Update cache key generation

In `_cache_key()`, replace:
```python
return f"query:{info.resource_id}:{digest}"
```
with:
```python
namespace = self._resource_namespace(info.resource_id)
return f"query:{namespace}:{digest}"
```

### Step 3: Update invalidation prefixes

In `_execute_put()` and `_execute_delete()`, replace:
```python
await self._cache.delete_prefix(f"query:{info.resource_id}:")
```
with:
```python
namespace = self._resource_namespace(info.resource_id)
await self._cache.delete_prefix(f"query:{namespace}:")
```

### Step 4: Replace instance generation with resource-scoped cache-backed generation

Remove `self._generation: int = 0` from `__init__`.

Add:
```python
async def _current_generation(self, resource_id: str) -> int:
    namespace = self._resource_namespace(resource_id)
    value = await self._cache.get(f"_daf_gen:{namespace}")
    return value if isinstance(value, int) else 0

async def _advance_generation(self, resource_id: str) -> None:
    namespace = self._resource_namespace(resource_id)
    current = await self._current_generation(resource_id)
    await self._cache.set(f"_daf_gen:{namespace}", current + 1)
```

Update `_execute_query()`:
```python
cached = await self._cache.get(cache_key)
if cached is not None:
    current_gen = await self._current_generation(info.resource_id)
    if cached.get("generation") == current_gen:
        return await self._handle_cache_hit(...)
return await self._execute_cache_miss(cache_key, info, user)
```

Update `_execute_cache_miss()`:
```python
current_generation = await self._current_generation(info.resource_id)
data = await self._repository.get(info.resource_id)
...
raw_data = copy.deepcopy(data)
...
await self._cache.set(cache_key, {
    "raw": raw_data,
    "transformed": data,
    "generation": current_generation,
})
```

Update mutation methods to call `await self._advance_generation(info.resource_id)` after successful mutation.

### Step 5: Add `import copy`

Add `import copy` to the imports in `src/daf/core/access.py`.
